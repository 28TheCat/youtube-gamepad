## 提交顺序

1. 阅读检查报告，修复或明确解决报告列出的失败项。
2. 完成 Chrome / Edge 与实体手柄验收，保留结果。
3. 将隐私政策发布到公开 HTTPS 地址，并在访客未登录时确认可访问。
4. 提供可用的公开支持入口；仓库地址目前尚未确认可公开使用。
5. 注册开发者账号，将候选 ZIP、图片与文案填入商店后台，核对隐私披露和权限说明。
6. 复核后提交审核。当前素材包不表示已提交或已通过商店审核。

隐私政策网页是静态文件，可以放到已有网站或公开静态托管服务。当前文件仍在本机，尚未公开发布。
